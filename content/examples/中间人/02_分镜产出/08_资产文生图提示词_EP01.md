# 资产文生图提示词 EP01

> 用途：为 `05_资产登记` 里的资产生成参考图。这些参考图是分镜面板 `@图N` 的绑定对象——先出资产图，再拿资产图做图生图/角色一致性跑分镜。
> 规范：角色遵循 art_character（四视图设定图 / 素颜底模 / 月白背景）；道具遵循 art_prop（四宫格 / 纯静物 / 无人）；场景遵循 art_scene（单画面主视图 / 无人物 / 前中后景）。风格：2D 国风二次元新国潮。
> 用法：任一文生图工具（grok.com 网页 / 即梦 / Seedream / Nanobanana）直接贴 Prompt。角色建议画幅 4:1，道具 1:1，场景 9:16（本项目竖屏）。
> ⚠️ 叶莲（黑衣醉客）是 EP01 悬念钩子，参考图也**只给背影/半掩态**，正脸留到 EP02。

## 出图顺序建议

1. 先出 3 张**场景图**（301 / 301-N / 302）——它们承载全部光影，是分镜的底。
2. 再出 3 个**主要角色**（101 舒十七 / 102 计明康 / 104 叶莲悬念态），103 黑小三次之。
3. 最后出 5 个**道具**四宫格。
4. 拿到资产图后，回到 `07_分镜面板`，把每条 `@图N` 绑定到对应资产图，用图生图/角色一致性模式跑 25 镜首帧。
