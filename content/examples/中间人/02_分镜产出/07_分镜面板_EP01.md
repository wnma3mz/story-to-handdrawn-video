# 分镜面板 EP01（storyboardPanel · 首位帧模式）

> 模式：首位帧模式（每镜独立一组，track 递增，shouldGenerateImage=true，出图提示词按首帧原则）。风格技法：2D 国风二次元新国潮。提示词模式：模式A（Seedream / 中文），用户未指定模型故取默认。
> 硬约束落地：videoDesc 与 prompt **均不含任何光影/色温/明暗/色调词**（由场景资产图承担）；台词/音效不进提示词；正文以 `@图N` 绑定参考图。

## 人物空间位置与朝向基准表（第2步预分析）

- **场1/场2（雅阁 301）**：舒十七 → 中后·高位（斜倚栏边居高），面朝右；计明康 → 中前·低位（前倾／跪地居下），面朝左、微仰头。180° 视轴锁定，全场不跳轴。
- **场3（雅阁·夜 301-N）**：舒十七 → 中中，正侧面朝右／背面望月（独处）。
- **场4（面馆 302）**：黑衣醉客 → 中前·伏桌，面部埋于臂弯（半掩）；舒十七 → 右中·贴坐醉客身侧，正侧面朝左（看向醉客）；黑小三 → 左中→左后（灶边→柜台），面朝右。舒十七贴坐醉客，与前三场疏离感反差。
