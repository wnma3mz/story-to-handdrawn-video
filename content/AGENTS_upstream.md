# Toonflow Adapter Kit Agent 入口

本仓库以“无运行代码、可跨 Agent 交接”的方式，把小说处理成外部视频平台可消费的生产包。

## 接手任务时必须读取

1. `docs/04_Agent标准作业流程.md`
2. 当前项目的 `00_项目配置.md`
3. 当前项目的 `00_项目状态.md`
4. 状态文件列出的所有已批准上游产物

不要只凭聊天摘要继续工作。文件是唯一事实来源。

## 执行规则

- 严格按 S0→S8 顺序执行，不越过未通过的质量门。
- 每次只负责状态文件中标记为 `IN_PROGRESS` 的一个阶段。
- 开始前把该阶段写为 `IN_PROGRESS`；完成并自审后写为 `REVIEW`；验收通过后写为 `APPROVED`。
- 上游产物为 `APPROVED` 后视为锁定。若必须修改，先把所有受影响下游阶段回退为 `NOT_STARTED`。
- 全剧使用一份全局资产登记表。角色 `1xx`、道具 `2xx`、场景 `3xx`；ID 不按集重置，不得重复或改号。
- 剧本批准后，台词锁定。导演规划、分镜表、分镜面板中的台词必须逐字一致。
- 分镜表与分镜面板禁止加入光影、色温、明暗和色调词；这些信息只放在场景参考图中。
- 不生成视频。本仓库的终点是参考图、逐镜提示词和跨电脑交付清单。
- 不把 `script_agent_decision.md` 或 `production_agent_decision.md` 中依赖 Toonflow 运行时工具的调用指令照搬到便携流程；只吸收其决策、执行和监督原则。

## 完成定义

只有当状态文件中的 S0-S8 全部为 `APPROVED`，所有目标集均有剧本、导演规划、分镜表和分镜面板，所有被引用资产均有本地参考图，且交付验收无阻断项时，才可以宣称“整部小说流程完成”。
