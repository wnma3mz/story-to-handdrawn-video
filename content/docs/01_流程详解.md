# 01 流程详解

> 从一部小说到 AI 短剧分镜的全链路。每一步：**做什么 → 读哪个 skill → 产出什么 → 对照哪个样例**。
> 你在对话式 AI 里「扮演」对应 Agent 层，把该步的 skill 当系统提示词贴进去，再喂输入，即可产出。

---

## 总览

```
scriptAgent（小说 → 剧本）
  步骤1 故事骨架 skeleton
  步骤2 改编策略 adaptation
  步骤3 剧本 script
        ↓
productionAgent（剧本 → 分镜）
  步骤4 导演规划 director_plan
  步骤5 衍生资产分析 + 资产登记 derive_assets
  步骤6 资产文生图提示词 generate_assets（本 kit 产提示词，出图交给你的图工具）
  步骤7 分镜表 storyboard_table
  步骤8 分镜面板 storyboard_panel
        ↓
  （步骤9 出图 / 出视频 —— 交给外部图/视频工具，本 kit 只到提示词为止）
```

每一步的产出都是下一步的输入。**先把项目配置（`templates/00_项目配置.md`）填好**，它贯穿全程（集数/时长/画幅/题材/画风）。

---

## 步骤1 · 故事骨架（skeleton）

- **做什么**：把整本小说压成短剧骨架——故事核、人物小传、三幕结构、逐集分集、股价级反转登记表。
- **读哪个 skill**：`skills/script_execution_skeleton.md`（＋你选的题材 `skills/story_skills/<题材>.md` 里的叙事技法）。
- **输入**：小说全文 txt ＋ 项目配置。
- **产出**：`01_故事骨架.md`。
- **对照样例**：`examples/中间人/01_剧本产出/01_故事骨架.md`。
- **要点**：分集要卡在钩子上断（每集末留反转/悬念）；股价级反转＝观众预期的价格曲线，每次反转都要「拉高—砸盘」。

## 步骤2 · 改编策略（adaptation）

- **做什么**：定核心改编原则、删减决策（哪些线砍、哪些人物并）、世界观怎么在短剧里轻量呈现。
- **读哪个 skill**：`skills/script_execution_adaptation.md`。
- **输入**：小说全文 ＋ 步骤1 骨架。
- **产出**：`02_改编策略.md`。
- **对照样例**：`examples/中间人/01_剧本产出/02_改编策略.md`。
- **要点**：短剧节奏快，原著的慢热铺垫、支线、心理描写多半要砍；保留「爽点/反转/情绪钩子」。

## 步骤3 · 剧本（script）

- **做什么**：把某一集写成分集台词脚本（scriptItem 格式：场景/人物/台词/动作）。
- **读哪个 skill**：`skills/script_execution_script.md`（＋题材叙事技法）。
- **输入**：骨架 ＋ 改编策略 ＋ 目标集号。
- **产出**：`03_剧本_EPxx.md`。
- **对照样例**：`examples/中间人/01_剧本产出/03_剧本_EP01.md`。
- **红线**：**台词一旦定稿，后续分镜零删改**——分镜表/面板里的台词必须与此处逐字一致。

---

> 以上 scriptAgent 三步产出「剧本」。下面进入 productionAgent，把剧本变成可出图的分镜。

---

## 步骤4 · 导演规划（director_plan / scriptPlan）

- **做什么**：把剧本拆成结构化的分场规划——每场的场景、参演角色、情绪基调、镜头节奏预设。
- **读哪个 skill**：`skills/production_execution_director_plan.md`（＋画风导演技法 `skills/art_skills/<画风>/director_storyboard*.md`）。
- **输入**：步骤3 剧本。
- **产出**：`04_导演规划_EPxx.md`。
- **对照样例**：`examples/中间人/02_分镜产出/04_导演规划_EP01.md`。

## 步骤5 · 衍生资产分析 + 资产登记（derive_assets）

- **做什么**：从剧本/规划里抽出所有需要出参考图的资产——角色、道具、场景（含衍生态，如「同一雅阁的夜景」），给每个分配一个 `id`。
- **读哪个 skill**：`skills/production_execution_derive_assets.md`。
- **输入**：剧本 ＋ 导演规划。
- **产出**：`05_资产登记_EPxx.md`（id / name / 说明 三列表）。
- **对照样例**：`examples/中间人/02_分镜产出/05_资产登记_EP01.md`。
- **要点**：`id` 是后面分镜表/面板 `@图N` 绑定的锚。角色/道具/场景各自编号段（本样例用 1xx/2xx/3xx）。**外观描述交给图片资产，不进分镜提示词正文**。

## 步骤6 · 资产文生图提示词（generate_assets）

- **做什么**：为步骤5 每个资产写一条文生图提示词。角色＝四视图设定图，道具＝四宫格静物，场景＝单画面主视图。
- **读哪个 skill**：`skills/art_skills/<画风>/art_character.md` / `art_prop.md` / `art_scene.md`。
- **输入**：资产登记。
- **产出**：`08_资产文生图提示词_EPxx.md`，**拿去你的图工具（grok.com / 即梦 / Seedream / Nanobanana）出图**。
- **对照样例**：`examples/中间人/02_分镜产出/08_资产文生图提示词_EP01.md`。
- **要点**：角色素颜底模、基础服装、无发饰、月白背景 `#E8EAF5`、四视图一致、6-7 头身；道具纯静物无人无手；场景无人物、前中后景、空气透视。**资产图承载全部光影**，所以分镜提示词里不再写光影。

## 步骤7 · 分镜表（storyboard_table / storyboardTable）

- **做什么**：把每场拆成「片段（≤15s）→ 逐镜（单镜≤8s）」，逐镜写画面/时长/景别/运镜/台词/音效。
- **读哪个 skill**：`skills/production_execution_storyboard_table.md`（＋画风 `director_storyboard_table_style.md`＋题材 `director_storyboard_table_narrative.md`）。
- **输入**：导演规划 ＋ 资产登记（引 id）。
- **产出**：`06_分镜表_EPxx.md`（`<storyboardTable>` 包裹，场头＋片段＋markdown 表）。
- **对照样例**：`examples/中间人/02_分镜产出/06_分镜表_EP01.md`。
- **红线**：① 台词零删改；② **画面描述/表内禁出现光影/色温/明暗/色调词**（交给场景资产图）；③ 禁 BGM，只写音效；④ 长台词（>20 字）拆镜；⑤ 出场角色必须都在画面里；⑥ 每条镜必引所属场景 id，可辨识的角色/道具（含背影/局部）一律引 id。

## 步骤8 · 分镜面板（storyboard_panel）

- **做什么**：给每一镜写最终的 AI 出图提示词，用 `@图N` 绑定步骤6 的资产参考图。
- **读哪个 skill**：`skills/production_execution_storyboard_panel.md`（＋ `skills/production_skills/storyboard_prompt_techniques.md`）。
- **输入**：分镜表 ＋ 资产登记。
- **产出**：`07_分镜面板_EPxx.md`。两种模式二选一：
  - **首位帧模式**：每镜独立一组，`track` 递增，`shouldGenerateImage=true`，提示词按首帧原则写（本样例用的就是这个）。
  - **纯文本多参模式**：不写 prompt/不出图，只堆参考图，靠视频模型多参生成。
- **对照样例**：`examples/中间人/02_分镜产出/07_分镜面板_EP01.md`。
- **红线**：videoDesc 与 prompt **均不含任何光影/色温/明暗/色调词**；台词/音效不进提示词；正文以 `@图N` 绑定参考图；每组结构【画面】【风格】。

---

## 步骤9 · 出图 / 出视频（kit 之外）

拿 `07_分镜面板` 的每条 prompt，把 `@图N` 换成步骤6 出的对应资产图，进你的图工具跑首帧（图生图/角色一致性），再进视频模型跑镜头。**本 kit 只负责到提示词，出图出片交给外部工具。**

---

## 一句话流水线

配置 → 骨架 → 策略 → 剧本 →（转 production）→ 导演规划 → 资产登记 → 资产提示词/出图 → 分镜表 → 分镜面板 → 出图出片。
